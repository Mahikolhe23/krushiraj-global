# Krushiraj Global

Premium agricultural brand website for Krushiraj Agro Pvt. Ltd.

## Visit the website

**Live site:** https://mahikolhe23.github.io/krushiraj-global/

The site is published with GitHub Pages. Every push to `main` runs the deployment workflow in `.github/workflows/deploy.yml`.

## Run locally

```sh
npm install
npm run dev
```

To create a production build locally:

```sh
npm run build
```

## Update product content

Edit `src/data/products.ts` to update the product names, descriptions, images, and accessibility text.

Contact details in the site are placeholders and should be replaced before public business use.
